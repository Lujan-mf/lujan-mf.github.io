Lista de definición

HTML
Es un lenguaje de marcada que es utilizado para crear páginas web.
CSS
Es un lenguaje que define el aspecto visual, el diseño y la maquetación de los diocumentos escritos en HTML o XML
DOM
Es una interfaz de programación que representa los documentos HTML, XHTML o XML como una estructura jerárquica en forma de árbol de objetos y nodos
